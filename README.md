This program sends exactly one line, the excuse an AI agent gives its human for missing a deadline, as the whole entry and nothing else. It writes that line to entry.txt, validates it, and reads it back byte-for-byte before exiting.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
